# Security policy

## Reporting a problem with this repository

This repository contains methodology and tooling, not a running service. If you
find something in it that could harm a user of the skill — for example a tool
that sends traffic outside its stated bounds, or guidance that would lead a
hunter into an out-of-scope action — open a private security advisory on GitHub
or email the maintainer listed in `README.md`.

Do not open a public issue for that class of problem.

## What is in scope for this policy

- Tool behaviour that violates its documented bounds.
- Templates or guidance that could cause a hunter to break program rules.
- Any content that could be read as encouraging unauthorized testing.

## What is not in scope

- The security of third-party programs discussed in examples.
- Bounty outcomes.
- Disagreements about severity.

## Safe harbor for this repository

Testing this repository means running its tools against targets you are already
authorized to test. There is no hosted component to test.
